5.2 Conditional Logic


If &apos;Commercial&apos; is selected in Services Needed, show additional field: &apos;Property Size (approx. sq ft)&apos; — number input.


If &apos;HOA Common Area&apos; is selected in Property Type, show additional field: &apos;Management Company Name&apos; — text input.


URL parameter pre-selection: if ?service=roof-cleaning is in URL, pre-check &apos;Roof Cleaning&apos; in Services Needed. If ?area=brandon is in URL, pre-fill City with &apos;Brandon&apos;.


5.3 Form Behavior


Inline validation on blur with specific error messages.


reCAPTCHA v3 (invisible). Rate limit: 3 submissions per IP per hour.


Submission → Cloud Functions → Zoho CRM (create Lead) + SendGrid (auto-response email + internal alert).


Auto-response email: branded template confirming receipt, listing services requested, and setting 24-hour response expectation.


On-page success: replace form with confirmation panel: &apos;Thank you, [Name]! Your estimate request for [services] at [address] has been received. Expect a written estimate within 24 hours. Questions? Call (813) 555-0283.&apos;


GA4: form_start (first focus), form_submit (success). form_submit marked as Conversion.


Submit button: &apos;Request My Free Estimate&apos; — orange, full-width on mobile, 56px height, 700 weight.
