1. Page Strategy & Keyword Targets
1.1 Page Purpose
The /service-areas/ page is the geographic hub of Easy Clean Service’s local SEO architecture. It mirrors the /services/ page in structure but for location targeting rather than service targeting. This page sits one level below the homepage and one level above each of the 12 individual neighborhood landing pages. Its primary jobs are: (1) rank for broad “cleaning service near me” and “house cleaning Tampa area” queries where the user has not specified a neighborhood, (2) distribute link equity and crawl authority to all 12 neighborhood pages, (3) provide a visual directory (map + area cards) that helps visitors find their specific neighborhood, and (4) demonstrate geographic authority by listing every community Easy Clean serves, reinforcing the company’s service footprint for both search engines and AI answer engines.
This page must contain substantial unique content beyond a simple list of links. The unique elements are: an interactive service area map, a zip code reference table, a geographic coverage summary with specific community counts, and introductory copy that positions Easy Clean as the Tampa-area cleaning authority.

3.3 Interactive Map Specifications
  SECTION ID: #service-area-map  
* Platform: Google Maps JavaScript API with custom markers, or a lightweight alternative like Leaflet.js with OpenStreetMap tiles to avoid Google Maps costs.
* Center point: Tampa, FL (approximately 27.9506, -82.4572)
* Zoom level: 10 (shows the full service area from Wesley Chapel to Riverview)
* Markers: 12 custom pins, one at the geographic center of each neighborhood. Use the Easy Clean brand color for pin styling.
* Pin interaction: Click/tap opens an info window with the neighborhood name and a "View [Neighborhood] Page" link to /service-areas/[slug]/
* Mobile: Map should be touch-responsive. Consider a static image fallback for very slow connections.
* Lazy loading: Defer map initialization until the user scrolls to it, or load on a button click ("Show Map"), to avoid impacting page speed.
